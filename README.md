# ☁️ Monografía: Nubes

> *"Descubre el fascinante mundo de las nubes ☁️✨"*

Una página web educativa e informativa creada como uno de mis primeros proyectos prácticos mientras aprendía los fundamentos de desarrollo web con **HTML5**. El objetivo fue diseñar una monografía digital escolar para presentar diferentes tipos de nubes de forma clara, visual y atractiva.

---


## ✨ Contenido y características

- 📖 **Monografía informativa:** Fichas con descripciones claras sobre los principales tipos de nubes (Cumulonimbos, Cúmulos, Nimbostratus, etc.).
- 🖼️ **Tarjetas visuales (Cards):** Presentación del contenido en tarjetas limpias con imagen, texto descriptivo y botón de acción.
- 🎨 **Tema visual:** Interfaz con tonos oscuros/azulados inspirados en el cielo nocturno o de tormenta.
- 📚 **Recursos escolares:** Sección dedicada con enlaces y fotos de apoyo pensadas para tareas estudiantiles.

---

## 🛠️ Tecnologías utilizadas

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) Estructuración semántica de textos, imágenes, encabezados y botones.
